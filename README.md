# emailscrapper

A Python-based email scraper that extracts emails from websites and social media platforms.

## Features

- Scrapes email addresses from various websites.
- Supports integration with social media platforms like Facebook, Instagram, and LinkedIn.
- Stores scraped data in a database (MySQL/PostgreSQL).
- Provides an easy-to-use interface to view and export collected emails.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/juliandivakaran/emailscrapper.git
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

1. Run the scraper:
    ```bash
    python scraper.py
    ```

2. Configure the scraper in `config.py` to specify which websites or social media platforms to scrape.
